# UI assets

- `ONT_Plasmid_Analyzer_icon.ico`: Windows shortcut icon
- `ONT_Plasmid_Analyzer_icon.png`: source image for UI/package use

Company branding files are intentionally excluded from GitHub. To display a
fixed logo in the lower-left sidebar, place one of the following files in the
repository root on the internal server:

- `branding_sidebar_logo.svg` (recommended)
- `branding_sidebar_logo.png`

The SVG file is preferred because it remains sharp at different display scales.
